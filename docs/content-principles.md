# Content Principles

Context for Codex. You are not writing this content — Claude is. But knowing why
it is shaped this way helps you spot when something has gone wrong.

---

## The positioning rule

**Judgement, not procedure.**

- Show *why*, show what was rejected, show the diagnosis.
- Never publish exact prompts, settings, or copy-paste templates.

The reasoning: procedural content commoditises the agency — it says the value is
in the steps, and steps are free. Judgement content is unrepeatable. The more of
it you show, the more obvious it becomes that the hard part is not execution.

If a slide contains a step-by-step you could follow without hiring anyone, it has
drifted from the strategy. Flag it.

---

## The caption spine

Seven beats, compressed to 700–1000 characters:

1. Standalone opening line that creates a debt
2. Immediate deflation — the second line undercuts the first
3. Context with hard specifics (real numbers do the credibility work)
4. A signposted turn
5. **A reframe of the question itself** — the load-bearing beat
6. A portable one-liner
7. A humility or aside close

When compressing, context gets cut first. **The reframe never gets cut.**

Formatting: one idea per line, hard returns between nearly every sentence,
deliberate fragments, emoji as structure not decoration (4–5 maximum, never in
the opening line), bold reserved for the reframe and the closing line.

Two separate captions per post — LinkedIn (longer, more analytical) and
Instagram (tighter, more direct). Not the same text trimmed.

## Content buckets, strongest first

1. **Teardowns** — critique a real public ad, page or brand
2. **Diagnostics** — help them identify their problem, not solve it
3. **What we rejected** — options presented, one chosen, reasoning shown
4. **Cost of getting it wrong** — what broke, what it cost
5. **Myth-correction / POV** — take a real position
6. **Proof** — anonymised outcomes, % change
7. **Process / BTS** — the messy middle
8. **Quick tips** — sparingly; this is the bucket that commoditises
9. **Culture** — weakest, and mostly unusable without faces

## The anti-repetition system

Four axes. No pair repeats within a month.

**Hook grammar**
contradiction · question-reframe · number-led · correction · incomplete sentence

**Annotation device**
circle · underline · highlight block · strike-through · bracket · margin note ·
selection box

**Slide-1 composition**
type-only · type + occluding object · split frame · UI mimicry · screenshot + callout

**Story opener**
client scenario · public brand analysis · a number that sounds wrong ·
our own mistake

September's assignments are tracked in the `Device Tracker` sheet of the
spreadsheet. If two posts in a month share a hook grammar *and* an annotation
device, that is a content error — flag it.

---

## Client confidentiality

- Teardowns use **public brands only**, never clients.
- Screen recordings must not show client dashboards, names, or absolute figures.
- Percentage change is acceptable. Absolute revenue is not.
- Any behind-the-scenes content is reviewed before it leaves the building.

---

## AEO

Instagram professional accounts have been indexable by Google and Bing since
July 2025 — captions, alt text, hashtags and text within visuals all count.

Consequences for production:
- Alt text is a real field, written per post. Never blank, never generic.
- Text baked into slides is indexed, so it should read as language, not fragments.
- Captions open answer-first where the format allows.

Before publishing, confirm Instagram indexing is switched on:
Settings → Account Privacy → allow public content in search engine results.
Default is on, but it is opt-out-able.
